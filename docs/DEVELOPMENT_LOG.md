# Diário de desenvolvimento — Conecta+ React Starter Kit

> Histórico da **matriz**. Em novos projetos, manter este documento como modelo, mas iniciar um histórico próprio sem copiar resultados de testes de outros produtos.

## M00 — Fundação V1.0
- **Objetivo:** template React Web independente do KURIO.
- **Estrutura:** páginas, rotas, componentes, cliente HTTP, testes e documentação.
- **Decisão:** não incluir backend ou autenticação fictícia.
- **Identidade:** tema inicial Conecta+; símbolo `C+` provisório até inclusão da logo oficial original.
- **Evidência informada pelo usuário:** `npm.cmd install` concluído e home aberta no navegador via `npm.cmd run dev`.
- **Não verificado nesta conversa:** `typecheck`, build, testes unitários, E2E e Lighthouse.

## M00.DOC — Padronização documental
- **Objetivo:** tornar a matriz replicável para qualquer novo projeto React Web.
- **Entregáveis:** guia mestre, briefing, convenções, checklists, plano de testes, problemas e handoff.
- **Decisão:** separar resultados reais do starter de templates a preencher por projeto.
- **Status:** documentação preparada; sem execução adicional de testes.
