# Checklist — iniciar novo projeto a partir do Starter Kit

## Cópia e personalização
- [ ] Criar cópia do starter fora da pasta matriz
- [ ] Nomear pasta e `package.json` para o novo produto
- [ ] Atualizar `index.html`, título, favicon, SEO e textos
- [ ] Trocar logo provisória por marca oficial autorizada
- [ ] Configurar tokens de cores e tipografia do cliente
- [ ] Remover conteúdo demonstrativo não aplicável
- [ ] Definir rotas e páginas iniciais
- [ ] Definir API real ou ambiente mock explicitamente identificado

## Planejamento
- [ ] Preencher `PROJECT_BRIEF_TEMPLATE.md`
- [ ] Validar requisitos e critérios de aceite
- [ ] Registrar decisões em `DEVELOPMENT_LOG.md`
- [ ] Planejar testes no `TEST_PLAN_AND_RESULTS.md`

## Qualidade e entrega
- [ ] `npm.cmd install`
- [ ] `npm.cmd run typecheck`
- [ ] `npm.cmd run build`
- [ ] `npm.cmd test`
- [ ] `npm.cmd run test:e2e`
- [ ] Verificar desktop, mobile, imagens, rotas e formulários
- [ ] Auditar Lighthouse e anotar resultados **do projeto atual**
- [ ] Revisar privacidade, segurança, acessibilidade e SEO
- [ ] Atualizar `ISSUE_REGISTER.md` e `RELEASE_CHECKLIST.md`
- [ ] Criar README específico e documento de entrega
